# Salary & Experience Across Global Industries

This project analyzes global salary survey data to understand how experience, job roles, education, and industry influence compensation. It includes data cleaning, MySQL upload, SQL analysis, Excel tables, and a dashboard.

## Workflow
1. **Data Cleaning**  
   - Handled missing values, standardized formats, fixed inconsistencies, removed outliers  
   - Exported `salary_survey_cleaned.csv`

2. **MySQL Integration**  
   - Created database and table  
   - Imported cleaned data using Workbench / LOAD DATA  

3. **SQL Analysis (10 Queries)**  
   - Avg salary by industry & gender  
   - Total compensation by job title  
   - Salary by education  
   - Experience vs salary  
   - Highest-paying roles by country  
   - Additional compensation patterns  
   (All results exported as CSV)

4. **Excel Analysis**  
   - 10 sheets created for all SQL outputs  
   - PivotTables for salary distribution, experience trends, industry comparison  

5. **Dashboard**  
   - Visuals: salary by industry, experience levels, gender comparison, top-paying jobs  
   - Includes slicers for interactive filtering  

## Key Insights
- Salary rises strongly with experience  
- Tech & Finance offer highest pay  
- Education boosts earning potential  
- Major differences exist across countries and cities
